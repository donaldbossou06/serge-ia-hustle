Le concept

Ton agent arrete de foncer, il travaille comme un senior

Superpowers, c'est un plugin gratuit et open source (licence MIT) pour Claude Code et les autres agents de code. Une fois installe, il change la facon de travailler de ton assistant, pas juste ce qu'il sait.

Un debutant fonce et ecrit du code au hasard. Un senior, lui, pose d'abord les bonnes questions, cadre le besoin, ecrit un plan, code par petits pas testes, puis relit son propre travail. Superpowers installe exactement cette discipline dans ton agent, et elle se declenche toute seule des que tu lui demandes de construire quelque chose.

En clair, ce que Superpowers ajoute

  • Il te fait cracher le vrai besoin avant d'ecrire une ligne (phase de cadrage).
  • Il te montre la specification par petits morceaux lisibles, tu valides.
  • Il transforme la spec validee en plan d'execution clair et teste.
  • Il lance des sous-agents qui codent, s'inspectent et se corrigent seuls.

Pourquoi ca change tout

Traduit en temps gagne et en argent economise

2 joursa debugger du code bancal
→
1 passecadree, testee, propre

Le cout cache d'un agent qui fonce, ce n'est pas le premier jet. C'est tout le temps perdu ensuite a rattraper les cas oublies, les bugs, les fonctions a moitie faites. Un travail cadre des le depart, tu le paies une fois.

Sans Superpowers

  • L'agent devine ton besoin et part dans la mauvaise direction
  • Il ecrit beaucoup de code d'un coup, difficile a relire
  • Pas de tests, les bugs sortent chez toi, pas chez lui
  • Tu reprends tout a la main

Avec Superpowers

  • Il cadre le besoin avec toi avant de coder
  • Un plan valide, decoupe en petites taches
  • Chaque bout est teste (approche TDD)
  • Des sous-agents relisent et corrigent avant livraison

La methode

Installe-le, puis laisse-le travailler

1. Le plus simple, via le marketplace officiel de Claude, tape dans Claude Code :

Claude Code
> /plugin install superpowers@claude-plugins-official
Superpowers installe. Les competences se declenchent automatiquement.

2. Ou via le marketplace de l'auteur (mixe d'autres plugins utiles) :

Claude Code
> /plugin marketplace add obra/superpowers-marketplace
> /plugin install superpowers@superpowers-marketplace

3. Ensuite, tu ne changes rien a tes habitudes. Demande-lui de construire, et lance la phase de cadrage avec un message comme celui-ci :

A copier dans Claude Code
Je veux construire [decris ton projet en une phrase]. Avant d'ecrire du code, pose-moi les questions dont tu as besoin pour bien cadrer, puis montre-moi la specification par petits morceaux que je valide un par un.

Les erreurs a eviter

Pour en tirer le maximum

  • Sauter le cadrage. Si tu reponds trop vite a ses questions, il code sur du flou. Prends deux minutes pour bien repondre, tu les recuperes dix fois.
  • Vouloir tout d'un coup. Un gros projet en un seul prompt, meme cadre, reste risque. Decoupe en objectifs.
  • Ne pas relire le plan. C'est le moment le moins cher pour corriger le tir. Lis le plan avant de dire go.
  • Croire que c'est reserve aux devs. Meme pour un petit site ou un script, la discipline te fait gagner du temps.
