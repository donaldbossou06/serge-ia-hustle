Le concept

Auto, ce n'est pas « fais ce que tu veux »

Depuis peu, le mode Auto est le mode par défaut de Claude Code. Il enchaîne les actions tout seul, sans te demander à chaque étape. Mais ce n'est pas du n'importe quoi.

Un deuxième modèle, le classifieur, relit chaque action avant qu'elle passe. Il bloque tout ce qui dépasse ta demande, tout ce qui touche à un service qu'il ne reconnaît pas comme le tien, et tout ce qui sent le piège (un texte malveillant qui essaie de lui faire faire des bêtises). Tu gardes la vitesse, sans le risque.

La méthode

Le cadrer, étape par étape

1. Vérifie ton mode. Il est déjà sur Auto par défaut, sinon tu le changes dans /config.

terminal
$ claude
Mode de permission : Auto
Le classifieur relit chaque action avant qu'elle passe.

2. Ouvre ton fichier de réglages. C'est là que tu écris tes propres règles.

terminal
$ code ~/.claude/settings.json

3. Écris tes règles en français, dans deux listes. deny = interdit, aucune exception. ask = il te demande d'abord. Tout le reste, il le fait seul.

À coller dans settings.json
{
  "permissions": {
    "deny": [
      "Ne jamais envoyer le contenu du projet a un service exterieur",
      "Ne jamais supprimer definitivement des fichiers ou des donnees"
    ],
    "ask": [
      "Demander avant de publier ou de mettre un site en ligne",
      "Demander avant d'installer une nouvelle dependance"
    ]
  }
}

4. C'est tout. Les règles sont lues dans l'ordre, deny d'abord. La première qui correspond gagne, et rien ne peut passer au-dessus d'un deny, ni le classifieur, ni même ta demande.

Le bon réglage

Quoi mettre où

Tu écris ça dans...Ce que Claude faitExemple
denyIl ne le fait jamais, aucune exceptionSupprimer des données, sortir ton code du projet
askIl te demande avantPublier, installer une dépendance, dépenser
rien (le reste)Il le fait seul, en autonomieLire, écrire, tester, corriger ton code

Les erreurs à éviter

Ce qui te fait perdre le bénéfice

  • Ne mets pas tout en deny. Sinon tu retombes à valider sans arrêt. Réserve deny au vraiment dangereux, ask au sensible.
  • Écris des règles claires et concrètes. Le classifieur les lit comme des consignes, pas comme du code. Une phrase simple vaut mieux qu'un charabia.
  • Ne coupe pas les permissions pour aller plus vite. Le mode qui saute toutes les sécurités, c'est exactement là qu'on se fait avoir.
  • Garde Claude Code à jour. Le classifieur et les réglages évoluent souvent.
