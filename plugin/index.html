4 plugins gratuits pour Claude Code

Ces quatre plugins réduisent ta consommation de tokens et font durer ton abonnement beaucoup plus longtemps. Tous gratuits.

01

Headroom

Il se place entre toi et le modèle et ne laisse passer que ce qui compte. Il compresse le reste, donc même résultat avec bien moins de tokens.

Ouvrir le site → github.com/headroomlabs-ai/headroom
02

Graphify

Il transforme ton code en graphe de connaissances en indexant chaque fichier et chaque fonction. Claude ne relit plus tout le projet à chaque message.

Ouvrir le site → github.com/pleaseai/claude-code-plugins
03

Code Burn

Il te montre exactement où tu crames tes tokens : par coût, par modèle, par outil et par projet. Tu vois enfin ce qui te coûte cher.

Ouvrir le site → npx codeburn
04

Ponytail

Il pousse Claude Code à écrire seulement le code nécessaire. Ta consommation baisse fortement, sans perdre en précision.

Ouvrir le guide → github.com/DietrichGebert/ponytail

Chaque semaine, les meilleurs outils IA pour vendre plus et bosser plus vite.
